# AudioBloomAI Support

Need help with setup, permissions, presets, projector output, Syphon, or camera layers? Start here.

## Quick Setup Checklist

1. Install AudioBloomAI from [TestFlight](https://testflight.apple.com/join/AyHQBwgR), if testing slots are still available.
2. Open `Settings > Setup` in the app.
3. Choose one audio source type: `Microphone / Interface`, `All App Audio`, or `Single App Audio`.
4. Choose the matching microphone, system output, or running app.
5. Grant the macOS permission requested for that source.
6. Keep the renderer on `Milkdrop / projectM` for the main preset workflow.

If macOS asks you to relaunch AudioBloomAI after granting System Audio Recording access, quit and reopen the app before starting capture again.

## Report A Problem

For bug reports and feature requests, open an issue on GitHub:

[Open an AudioBloomAI issue](https://github.com/noktirnal42/AudioBloom/issues)

Helpful reports include:

- macOS version
- AudioBloomAI version
- audio source type you selected
- whether the issue happens with microphone, all-app audio, or single-app audio
- whether projector, Syphon, Deck B, or the camera layer was enabled
- a short description of what you expected and what happened instead

Please avoid posting private audio, screenshots, logs, credentials, or personal information in public issues.
