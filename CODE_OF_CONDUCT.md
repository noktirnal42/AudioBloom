# Code of Conduct

This project adheres to the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By participating, you are expected to uphold this code.

For enforcement or to report unacceptable behavior, please open a private security advisory or, if needed, contact the maintainers via a confidential channel (e.g., GitHub Security Advisory; see `SECURITY.md`).
